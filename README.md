# 💰 Personal Expense Tracker

A simple and efficient **Personal Expense Tracker** built using Python and Streamlit to help you manage your daily expenses, visualize spending patterns, and stay financially organized.

---

## 🚀 Features

* ➕ Add income and expenses
* 📊 Visualize spending with charts
* 📁 Store data locally (CSV / SQLite)
* 🔍 Filter transactions by date/category
* 🔐 (Optional) User authentication system
* 📈 Track balance over time

---

## 🛠️ Tech Stack

* **Frontend:** Streamlit
* **Backend:** Python
* **Database:** SQLite / CSV
* **Libraries:** Pandas, Matplotlib / Plotly

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/personal-expense-tracker.git
cd personal-expense-tracker
```

2. Create virtual environment:

```bash
python -m venv venv
```

3. Activate environment:

```bash
venv\Scripts\activate   # Windows
```

4. Install dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the App

```bash
streamlit run app.py
```
